# sudoku-solver

A Python-based application that solves 9x9 Sudoku puzzles using a classic backtracking algorithm, featuring a dynamic, real-time terminal-based visualization of the solving process.

## System Requirements

The application was designed and tested on **[Windows Terminal](https://apps.microsoft.com/detail/9n0dx20hk701)**, **v1.24.11321.0**.  
For a correct rendering of borders and characters, it is highly recommended to use a font that supports *ligatures* (e.g., **Cascadia Code**).
